# BITOMANCY

AI • TECH • DIGITAL GROWTH

A fast, static-first technology publication and digital-products website for bitomancy.in.

## Included
- Editorial homepage
- AI, Tech, How-To, SEO & Blogging, Reviews
- Search
- Article template/data
- Free tools
- Shop and Smart Copy PRO
- Newsletter/contact UI
- SEO metadata, canonical, Open Graph
- robots.txt and sitemap.xml
- RSS feed
- Responsive dark/light design
- AdSense-ready slots
- Affiliate/product CTA components

## Run locally
Python 3 is enough:

    python -m http.server 3000

Then open http://localhost:3000

No API keys are required for this starter build. AI tools are intentionally client-side demos until you connect a secure server-side AI provider.

## Publish
This is a static site and can be deployed to Cloudflare Pages, GitHub Pages, Netlify, or any static host.

Before launch:
1. Replace example article data with your Blogger content.
2. Replace the Smart Copy PRO checkout URL in `script.js`.
3. Add your analytics/AdSense IDs where marked.
4. Update `sitemap.xml`.
5. Connect bitomancy.in.
